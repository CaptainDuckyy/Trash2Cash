# Trash2Cash
Trash2Cash is a smart waste management system that aims to helps users find practical ways to manage their unwanted items, turn recyclable and reusable waste into potential income, as well as identifies waste items through uploaded photos. 
It provides recommendations like diy suggestions for recycling, reuse, selling price or it's proper disposal. 

OBJECTIVES:
   - Encourage proper waste segregation and responsible waste disposal
   - Help users identify different potential uses and value of unwanted items.
   - Provide accessible recycling and upcycling recommendations.
   - Promote the reuse and recovery of materials instead of immediately discarding them.

MAIN FEATURES:
  - Allows the users to submit multiple images, descriptions, and conditions.
  - uses an external API to identify item material categories.
